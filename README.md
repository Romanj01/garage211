# Гараж 211 — автономная сборка для GitHub Pages

Готовый статический сайт с локальным демо записи и админки. Node.js на хостинге не требуется. Публикация не выполнялась: эту сборку владелец загружает самостоятельно.

## Загрузка

1. Загрузите **содержимое** этой папки в корень выбранного GitHub-репозитория. `index.html` должен лежать в корне, без дополнительной вложенной папки. Сохраните `.nojekyll`.
2. В репозитории откройте Settings → Pages. Для публикации из ветки выберите основную ветку и папку `/(root)`.
3. Откройте адрес, который покажет GitHub Pages после публикации. Ресурсы используют относительные пути, поэтому сайт работает и по адресу репозитория, и на собственном домене.

Серверные файлы из другой, VPS-сборки, сюда загружать не нужно. Для сайта достаточно HTML, CSS, JS, PNG, SVG, `manifest.webmanifest` и `.nojekyll`. Файлы `*.mjs`, `package.json`, `start.cmd`, README и DESIGN нужны для локальной работы и справки.

## Как устроено демо

Кнопки записи, кабинет, перенос, загрузка фото, редактор услуг, расписание и настройки работают в хранилище текущего браузера. Демо-вход: **admin / 0123456789**. Это публичный тестовый пароль, а не защита общего сервера. Записи не отправляются в «Гараж 211». Настоящие письма и сообщения Telegram не отправляются. На главной отображается пояснение.

Изменения через админку сохраняются только у посетителя, который их сделал. Чтобы обновить начальный сайт **для всех**, измените `demo-seed.js` и загрузите изменённые файлы в GitHub. Для общей записи и общей админки используйте отдельную VPS-сборку.

## Локальный просмотр

Node.js 22+: `npm start` или `start.cmd`, затем `http://127.0.0.1:4336/garage211-github/`.

Не открывайте `index.html` двойным кликом: модулям нужен HTTP/HTTPS.

`npm run check` — синтаксис, модули и относительные пути. `npm test` — запись, кабинет, администрирование, фото и сброс в автономном демо.

Палитра и происхождение иллюстраций описаны в `DESIGN.md`.
